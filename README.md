# Бот-староста

Telegram-бот для студенческой группы.  
Автоматически напоминает о дедлайнах (сегодня и завтра) и поздравляет именинников.  
Участники группы могут добавлять дни рождения и просматривать дедлайны.  
Добавлять и удалять дедлайны может только староста.

## Возможности

### Для всех участников группы
- Добавить свой день рождения
- Посмотреть список всех дней рождения
- Посмотреть все дедлайны
- Посмотреть дедлайны по конкретному предмету
- Посмотреть прошедшие дедлайны

### Только для старосты
- Добавлять новые дедлайны (предмет, название, дата, комментарий)
- Удалять дедлайны

### Автоматические функции
- Каждый день в 9:00 бот поздравляет именинников в группе
- Каждый день в 9:05 бот присылает напоминания о дедлайнах на сегодня и завтра

### Безопасность
- Бот проверяет, состоит ли пользователь в группе. Если нет — доступ к командам закрыт.

## Технологии

- **Python**
- **aiogram** — библиотека для работы с Telegram Bot API
- **Flask** — веб-сервер для healthcheck на Render
- **APScheduler** + **pytz** — планировщик задач (ежедневные напоминания)
- **Supabase** — облачная PostgreSQL-база данных
- **Render** — хостинг бота
- **cron-job.org** — внешний пинг, чтобы бот не засыпал

|--------------------|-----------------------------------------------|--------------|

| `SUPABASE_KEY`     | API-ключ (anon/public) из настроек Supabase   | Да           |

## Установка и запуск

### Локальный запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <ссылка-на-репозиторий>
   cd <название-папки>
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   ```
   - Windows:
     ```bash
     venv\Scripts\activate
     ```
   - Linux / macOS:
     ```bash
     source venv/bin/activate
     ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Создайте файл `.env` в корне проекта:
   ```
   TELEGRAM_TOKEN=ваш_токен
   SUPABASE_URL=ваш_url
   SUPABASE_KEY=ваш_ключ
   ```

5. Запустите бота:
   ```bash
   python app.py
   ```

### Деплой на Render

1. Создайте новый **Web Service** на [render.com](https://render.com).
2. Подключите GitHub-репозиторий.
3. Укажите:
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python app.py`
4. В разделе **Environment** добавьте переменные:
   - `TELEGRAM_TOKEN`
   - `SUPABASE_URL`
   - `SUPABASE_KEY`
5. После деплоя добавьте ссылку сервиса (`https://ваш-сервис.onrender.com`) в [cron-job.org](https://cron-job.org) — пинг каждые 5 минут на `/` или `/health`.

Пример:
```
/add_deadline Матан | Лабораторная работа №3 | 2026-05-25 | Выполнить задания 1-5
```

## Архитектура

Бот работает по следующей схеме:

- Пользователь отправляет команды через Telegram
- Бот (aiogram) обрабатывает их через модули `birthdays.py` и `deadlines.py`
- Данные хранятся в Supabase (таблицы `birthdays` и `deadlines`)
- Ежедневные задачи выполняются через APScheduler
- Flask поднимает простой веб-сервер для healthcheck
- cron-job.org периодически пингует бота, чтобы он не засыпал на Render
